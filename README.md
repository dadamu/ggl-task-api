# GGL Task API

A RESTful task API written in Go, using [gin](https://github.com/gin-gonic/gin) and a DDD-style layered architecture.

## Requirements

- Go 1.27+ (see `go.mod`)
- Make
- Docker (optional)

## Quick start

```bash
make run                # start server on :8080
PORT=8090 make run      # custom port
```

- Health check: http://localhost:8080/healthz
- Swagger UI: http://localhost:8080/swagger/index.html

## API

| Method | Path          | Description   |
|--------|---------------|---------------|
| GET    | `/tasks`      | List tasks    |
| POST   | `/tasks`      | Create a task |
| PUT    | `/tasks/{id}` | Update a task |
| DELETE | `/tasks/{id}` | Delete a task |

Task fields:

| Field    | Type    | Description                       |
|----------|---------|-----------------------------------|
| `name`   | string  | Task name                         |
| `status` | integer | `0` = incomplete, `1` = completed |

## Development

```bash
make help     # list all targets
make check    # swag + tidy + fmt + vet + lint + test (same as CI)
make test     # unit tests with race detector
make cover    # coverage report
make lint     # golangci-lint
make swag     # regenerate swagger docs
```

Tool binaries (`golangci-lint`, `swag`) are installed into `bin/tools/` with pinned versions on first use.

## Configuration

| Env        | Default | Description             |
|------------|---------|-------------------------|
| `PORT`     | `8080`  | HTTP listen port        |
| `GIN_MODE` | `debug` | `debug` / `release` / `test` |

## Project layout

```
cmd/server/                  # entrypoint, wiring (composition root)
internal/
├── domain/                  # entities, value objects, repository interfaces
├── application/             # use cases
├── infrastructures/         # repository implementations, config
└── transport/http/          # gin router, handlers, DTOs
swagger/                     # generated by swag, do not edit
```

Dependency direction: `transport → application → domain ← infrastructures`.
